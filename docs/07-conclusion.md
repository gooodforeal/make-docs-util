# Заключение

«Люмен» задаёт распределённый контур управления уличным освещением: узлы сами оценивают занятость, заранее поднимают яркость по коридору LMP и согласуют уставки так, чтобы выдержать норму EN 13201 при минимальной энергии.

Ключевые решения документации:

- яркость не назначается городским сервером в реальном времени;
- протокол LMP умещается в одну 802.15.4-рамку;
- отказ связи переводит узел в безопасную яркость, а не в темноту;
- математически задача сведена к локальному консенсусу на срезе фотометрической матрицы $A$.

По имитационной оценке экономия относительно постоянного режима составляет около половины при сохранении равномерности. Следующий шаг вне учебного репозитория --- пилот на реальной улице и уточнение $A$ по ночным замерам люксметра.
