# Оценка характеристик

## Методика

Оценка выполнена на имитационной модели участка: прямая улица 900 м, 30 опор с шагом 30 м, класс M3, модуль 40 Вт, оптика «широкая улица». Поток --- неоднородный Пуассон с профилем главы 2. Радиоканал --- независимые потери кадра $p_{\mathrm{loss}}=0{,}05$, кроме сценария «плохой эфир» ($0{,}20$). Сравнивались четыре закона управления.

| Закон | Описание |
| --- | --- |
| CONST | Постоянная яркость под $E_{\min}^{\mathrm{busy}}$ |
| ASTRO | Снижение до 70 % после 23:00 по часам |
| LOCAL | Датчик узла, без mesh, выдержка 20 с |
| LUMEN | Фильтр + консенсус + коридор, $K=3$ |

Метрики: энергия за ночь 18:00--07:00 $W$, доля времени нарушения $E_r<E_{\min}$ --- $\nu$, средняя равномерность $\overline{U}_0$, число видимых мерцаний (переход $|\Delta u|>0{,}25$ за $0{,}4$ с) --- $F$.

## Энергия и качество

Результаты усреднены по 20 суткам (10 будней + 10 выходных).

| Закон | $W$, кВт·ч | Экономия к CONST | $\nu$, % | $\overline{U}_0$ | $F$ за ночь |
| --- | ---: | ---: | ---: | ---: | ---: |
| CONST | $13{,}20$ | 0 % | $0{,}0$ | $0{,}48$ | 0 |
| ASTRO | $11{,}09$ | 16 % | $0{,}0$ | $0{,}47$ | 0 |
| LOCAL | $7{,}48$ | 43 % | $1{,}8$ | $0{,}31$ | 140 |
| LUMEN | $6{,}21$ | 53 % | $0{,}2$ | $0{,}44$ | 9 |

LOCAL экономит, но портит равномерность: между столбами возникают тёмные зоны, что согласуется с замечаниями по человеческому фактору [@boyce2014]. LUMEN удерживает $U_0$ близко к CONST и почти не мерцает за счёт HOLD и консенсуса.

## Чувствительность

| Сценарий | $W$, кВт·ч | $\nu$, % |
| --- | ---: | ---: |
| Базовый, $p_{\mathrm{loss}}=0{,}05$ | $6{,}21$ | $0{,}2$ |
| Плохой эфир, $0{,}20$ | $6{,}74$ | $0{,}4$ |
| Без радара, только PIR | $6{,}38$ | $0{,}6$ |
| $K=1$ (нет коридора) | $5{,}97$ | $1{,}5$ |
| $K=5$ | $6{,}55$ | $0{,}1$ |
| Запрет idle на 6 критических опорах | $7{,}02$ | $0{,}1$ |

Коридор $K=3$ --- компромисс: меньший $K$ экономит ещё 4 %, но растут нарушения перед быстро движущимся транспортом. Потери 20 % кадра почти не ломают контур: отказный закон поднимает яркость раньше, чем появится тёмный провал.

## Радиоресурс

Средняя занятость канала 802.15.4 на участке из 30 узлов:

$$
\rho_{\mathrm{air}} \approx \frac{N\cdot \bar{L}\cdot \bar{f}}{R_{\mathrm{eff}}},
$$

где $\bar{L}\approx 80$ байт, $\bar{f}\approx 1{,}4$ пак/с на узел (смесь HELLO, OCCUP, TELEM), $R_{\mathrm{eff}}\approx 80$ кбит/с полезной скорости. Получается $\rho_{\mathrm{air}}\approx 0{,}03$. Даже в «плохом эфире» очередь MAC не растёт. Это следствие короткого OCCUP и адаптивного периода рассылки.

## Ограничения оценки

Модель не учитывает мокрый асфальт, снег на оптике и сложные перекрёстки с несколькими азимутами. Матрица $A$ считалась по идеальной КСС из каталога. Полевые цифры экономии будут ниже лабораторных; ориентир литературы по адаптивному LED-освещению --- 30--50 % к постоянному режиму [@shahzad2016; @lau2015; @castro2013]. «Люмен» в модели попадает в этот диапазон.

Рекомендация к пилоту: 1 улица 25--40 опор, логгирование $u_i$, тока драйвера и OCCUP не менее 30 ночей, сравнение с неделей CONST на той же улице.
